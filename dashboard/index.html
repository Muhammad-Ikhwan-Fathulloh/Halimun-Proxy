Active controls

  • AES-256-CBC encryption of tokens and request bodies
  • HMAC-SHA256 signature over canonical JSON, with body hash binding
  • Nonce replay protection and token expiry checks
  • SSRF protection: private addresses blocked unless whitelisted
  • Redirects disabled; upstream timeouts and response size limits
  • Per-IP rate limiting

Guide

  1. Create the keys

    Generate the keys with the Docker Hub image and save them to .env:

    docker run --rm ikhwan17/halimun-proxy:latest --keygen --format=env

  2. Configure

    Copy config.example.yaml to config.yaml. Keep secrets in .env, not in the file.

  3. Start

    docker compose pull
docker compose up -d

  4. Connect a client

    Use the same AES key, HMAC key, XOR key, and alphabet in your client. The Python client in examples/clients/python is the reference implementation. See docs/PANDUAN.md for the protocol.
