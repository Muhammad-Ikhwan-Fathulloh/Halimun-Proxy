Operation Guide
1
Initialize Configuration

Create a `config.yaml` in your root directory. This defines your server ports, admin credentials, and backend mappings.

server: host: "0.0.0.0" port: 80 admin_api_key: "your-secret-key" services: - name: "app-1" url: "http://target:8080"
2
Generate Secrets

Navigate to the Key Management panel and click "Generate New Bundle". Copy these keys into your development environments.

3
Deploy Proxy

Halimun is Docker-native. Run the cluster with one command:

docker-compose up -d
4
Encrypt Client Request

On your client side, wrap your target URL with a Halimun Token. Example (Node.js):

const token = encrypt({ api_url: "http://target/api/login", method: "POST", nonce: uuid(), timestamp: Date.now() }); // Send to proxy fetch('http://proxy/proxy/1/seg1/seg2/HIDDEN_TOKEN/seg4/seg5');
